Ajouter un nouveau circuit

L'application a été conçue pour être totalement évolutive. Pour ajouter un nouveau circuit, il vous suffit d'ajouter une entrée dans l'objet workouts au début du script :

workouts.mon_nouveau_circuit = { id: "mon_nouveau_circuit", name: "Circuit Jambes & Cardio", category: "Bas du corps", totalRounds: 3, prepTime: 10, workTime: 45, restTime: 15, roundRestTime: 60, exercises: [ { id: 1, name: "Squats sautés", description: "Flexion 90° et impulsion", tips: "Amortis en douceur" }, { id: 2, name: "Fentes alternées", description: "Genou arrière frôlant le sol", tips: "Garde le buste droit" }, { id: 3, name: "Gainage chaise", description: "Dos au mur à 90 degrés", tips: "Respire calmement" } ] };

Il apparaîtra alors automatiquement sur votre menu d'accueil avec son badge, sa durée calculée et tous ses réglages !
